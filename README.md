# Atlas Solutions — Landing Page

Sitio web estático bilingüe (ES/EN) para Atlas Solutions.

## Archivos
- `index.html` — la página completa
- `vercel.json` — configuración para Vercel

## Deploy en Vercel via GitHub

### 1. Subir a GitHub
```bash
git init
git add .
git commit -m "Atlas Solutions landing page"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/atlas-solutions.git
git push -u origin main
```

### 2. Conectar con Vercel
1. Entra a https://vercel.com y crea cuenta (gratis)
2. Clic en **"Add New Project"**
3. Selecciona el repositorio `atlas-solutions`
4. Deja todo por defecto → clic en **"Deploy"**
5. En ~30 segundos tienes tu URL: `atlas-solutions.vercel.app`

### Dominio propio (opcional)
En Vercel → tu proyecto → **Settings → Domains** → agrega tu dominio.
